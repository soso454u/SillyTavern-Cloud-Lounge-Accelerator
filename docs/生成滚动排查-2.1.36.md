# 2.1.36 生成滚动排查

## 已确认的范围

先核对目标仓库 `main`：远端与本地均为 2.1.35，提交 `501ea2011b2edb067171d799ce0895a5db51df1f`。

用户提供的约 9.8 秒 iPhone 录屏中，流式文字仍在增长，上下滑动期间消息气泡有短暂截断和大片空白，随后恢复。画面不能给出主线程任务耗时、合成层状态或接口返回时间，不能仅凭录屏认定某个主题、扩展或 Safari 本身是唯一原因；也未观察到整个应用退出。

对照 [SillyTavern 1.18.0 `51ad27fb8` 的原生代码](https://github.com/SillyTavern/SillyTavern/blob/51ad27fb8/public/script.js)：

- `StreamingProcessor.generate()` 先更新接收到的完整 `result` 和 reasoning，再向扩展广播 `STREAM_TOKEN_RECEIVED`，然后按原生 `Stopwatch` 尝试更新预览。
- `onProgressStreaming()` 处理整段文本、reasoning、Swipe 元数据，再运行 `messageFormatting()`，通过 `innerHTML` 或 `applyStreamFadeIn()` 更新整段消息，并按原生滚动锁决定是否贴底。插件 2.1.35 暂停代码扫描后，这部分工作仍会继续。
- `finalizeIntermediaryMessage()` 首先以 `isFinal=true` 完整调用同一方法，然后处理复制、reasoning、工具调用收尾等；`onFinishStreaming()` 在此之后保存。停止正常生成后也会进入原生收尾。

这确认了可减少的重复工作，不足以证明减少它就能消除录屏中的全部绘制异常。

## 实现与取舍

模块在 `APP_READY` 之后随现有延迟包加载，仅由“聊天与重美化优化”开关控制。通过原生模块的实时绑定获取当前流式实例，只包装该实例的 `onProgressStreaming()`，不改写类原型。

中间预览按触屏 50ms、桌面约 33ms 的最小间隔放行；真实拖动超过 10px 或聊天区滚轮输入后改为 125ms。被动事件监听不阻止原生手势，也不读取布局或设置滚动位置。惯性滚动可短时续期，但距离最近真实手势最多 800ms，避免自动贴底让低频档永久持续。耗时较长的原生渲染使用至多 125ms 的自适应恢复间隔；这里限制的是附加间隔，无法拆分单次很重的原生格式化任务。

原生本来较低的 FPS 仍限制调用次数。触屏滑动期间的文字会以较大的批次出现，用来减少整段消息重算、DOM 替换和绘制竞争。新消息 ID 的首次预览和所有最终渲染立即通过，不等待节流期限。

不保留被跳过的文字，不创建延迟重放或尾帧计时器；下一次原生放行预览使用当前完整快照，最终渲染使用原生提供的完整正文。网络数据、token 事件和原生保存协议未修改；原生 `streaming_fps`、`stream_fade_in` 未赋值或保存。停止、结束、切换会话和停用时恢复原方法；未知接口、代写用户输入与不能写入的实例走原生路径。若别的扩展之后替换了同一方法，清理时不会覆盖它。

## 检查与复现

- `npm test`：195 项通过，含 13 项流式单元测试，覆盖最终渲染、耗时恢复、手势/惯性边界、低帧率保留、停止/切换、扩展包装共存和原生异常透传。
- `scripts/check-client-bundle.mjs`：实际发布包、桌面与模拟 iPhone 的 Chromium。核对延迟加载、实时实例绑定、80 个 token 事件全部送达、预览减少、最终 DOM/聊天正文一致、原生偏好及设置保存次数不变，生成中停用恢复原方法。
- `scripts/check-chat-interaction.mjs`：既有桌面/触屏真实 DOM 复制、按钮身份、选区、弹窗、扫描暂停与清理检查通过。
- `scripts/check-native-streaming.mjs`：直接提取并执行上面固定版本的官方 `StreamingProcessor` 和 `Stopwatch`，其格式化、DOM、reasoning 辅助接口和持久化依赖使用隔离替身。普通/继续/Swipe 各验证正常与停止两条路径；检查 token 事件、原生最终渲染、reasoning、token 计数、保存内容与还原。源码通过 SHA-256 对照确认，未把第三方源码复制进插件。

原生检查可使用本地 SillyTavern 源码运行：

```sh
CLA_NATIVE_SCRIPT=/path/to/SillyTavern/public/script.js \
CLA_NATIVE_UTILS=/path/to/SillyTavern/public/scripts/utils.js \
node scripts/check-native-streaming.mjs
```

这些检查没有加载用户聊天、预设、完整主题或其他扩展，也没有在 iPhone Safari 原生进程上复现录屏。更新后仍需在同一手机上生成并上下滑动复验；本版不宣称提高模型输出速度或彻底修复所有空白、卡顿与应用退出。
