# 云酒馆加速器 2.1.1 完整使用教程

## 一、先选择安装模式

云酒馆加速器由两部分组成：

- UI 扩展：页面启动、聊天、正则、预设、拖拽和抽屉优化。
- 服务端插件：提供根作用域 Service Worker，用于程序静态资源缓存。

| 你的环境 | 推荐方式 |
| --- | --- |
| 自己管理 SillyTavern 服务器、容器或本机目录 | 安装 UI + 服务端插件 |
| 只能在酒馆内安装扩展 | 只安装 UI |
| 没有 HTTPS，也不是 localhost | 先用 UI；静态缓存会显示“需要 HTTPS” |

只安装 UI 也能使用聊天和界面优化。服务端插件缺失不会阻止扩展启动。

## 二、一键安装完整增强

下面四段命令分别对应你提供的 VPS、Android、Mac 和 Windows 部署教程。它们同时用于首次安装与以后更新：安装器会更新服务端插件和 UI 扩展、备份配置，不会自动启动或重启 SillyTavern。

### VPS / 1Panel XTerminal

教程使用 `root` 用户把酒馆安装在 `/root/SillyTavern`，直接复制：

```bash
cd /root/SillyTavern
curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash
```

如果你用的不是 `root` 用户，或者酒馆不在这个位置，只修改第一行路径。

### Android / Termux

安卓教程把酒馆安装在 Termux 用户目录的 `~/SillyTavern`。先保证 Termux 有 `curl`，再执行安装：

```bash
pkg install curl -y
cd ~/SillyTavern
curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash
```

请在 Termux 中执行，不是在手机浏览器地址栏或 MT 管理器中执行。安装后重新运行 `cd ~/SillyTavern && bash start.sh`。

### Mac / 终端

Mac 教程把酒馆安装在当前用户目录的 `~/SillyTavern`，在“终端”中直接复制：

```bash
cd ~/SillyTavern
curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash
```

安装后重新运行 `cd ~/SillyTavern && ./start.sh`。

### Windows / PowerShell

Windows 教程的实际酒馆根目录是 `D:\SillyTavern\SillyTavern`。请打开 PowerShell（不是 CMD），复制：

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.ps1'))) -SillyTavernRoot 'D:\SillyTavern\SillyTavern'
```

如果你安装在其他盘或其他文件夹，只替换最后的路径。安装后关闭旧的 SillyTavern 窗口，再双击根目录中的 `Start.bat`。

### 自定义路径通用写法

Linux、Android 和 Mac 也可以不先 `cd`，直接把真实根目录传给脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash -s -- /你的/SillyTavern/路径
```

脚本完成后请手动重启 SillyTavern。安装器不会猜测并重启你的 Termux 进程、Mac 终端、Windows 窗口、1Panel 容器或系统服务。

普通安装不会改动性能开关。VPS、Android 和 Mac 可追加 `--keep-alive`、`--lazy-characters` 或 `--fast-start`；PowerShell 对应使用 `-KeepAlive`、`-LazyCharacters` 或 `-FastStart`。`FastStart` 只是前两项的组合，不代表所有环境都一定更快。

一键安装会：

1. 把仓库安装到 `plugins/cloud-lounge-accelerator/`。
2. 把 UI 文件安装到默认用户的扩展目录。
3. 备份需要调整的配置。
4. 自动启用并验证 `enableServerPlugins: true`。

## 三、手动安装

### 只安装 UI

在 SillyTavern 中打开“扩展 → 安装扩展”，输入：

```text
https://github.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator
```

安装后刷新页面。打开“扩展设置 → 云酒馆加速器”即可看到三个开关。

### 安装服务端插件

进入 SillyTavern 根目录：

```bash
git clone https://github.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator.git plugins/cloud-lounge-accelerator
```

已有目录时更新：

```bash
git -C plugins/cloud-lounge-accelerator pull
```

确认目录结构：

```text
SillyTavern/
├─ plugins/
│  └─ cloud-lounge-accelerator/
│     ├─ package.json
│     ├─ manifest.json
│     ├─ index.js
│     └─ server/
│        ├─ index.js
│        └─ worker-template.js
└─ config.yaml
```

确认 `config.yaml`：

```yaml
enableServerPlugins: true
```

角色较多时可再确认 SillyTavern 官方性能设置：

```yaml
performance:
  lazyLoadCharacters: true
  memoryCacheCapacity: '100mb'
  useDiskCache: true

cacheBuster:
  enabled: false
```

不要创建重复的 `performance:` 或 `cacheBuster:` 段；只修改现有配置项。

重启后，日志应包含：

```text
Initializing plugin from .../cloud-lounge-accelerator/server/index.js
```

## 四、配置 HTTPS

Service Worker 只能在 HTTPS 或 localhost 使用。云服务器上应从 `https://你的域名` 访问，而不是裸 `http://IP:端口`。

没有自有域名时，可以使用 `sslip.io` 这类把 IP 编入主机名的公共解析服务。例如服务器 IP 为 `23.94.194.240`：

```text
23-94-194-240.sslip.io
```

在 1Panel 中：

1. 新建反向代理网站，主域名填上述主机名。
2. 上游填 `http://127.0.0.1:8000`，端口按实际修改。
3. 用 HTTP 验证申请 Let's Encrypt 证书。
4. 开启 HTTPS，并传递 `X-Forwarded-Proto $scheme`。
5. 此后从 HTTPS 地址进入酒馆。

如果证书报错、页面不是安全上下文或浏览器策略禁用 Service Worker，页面缓存会保持关闭，其他优化仍可使用。

## 五、1Panel 反向代理静态优化

仓库中的 [`1panel/nginx-static.conf.example`](../1panel/nginx-static.conf.example) 只匹配程序静态目录。

操作前：

1. 备份当前站点配置。
2. 把片段放进已有 `server { ... }` 内。
3. 把 `proxy_pass http://127.0.0.1:8000;` 改为当前 SillyTavern 上游。
4. 如已有相同正则 `location`，合并配置，不要叠加冲突规则。
5. 通过 1Panel 配置检查后再重载 OpenResty/Nginx。

不要缓存以下内容：

```text
页面导航
/api/
/characters/
/backgrounds/
/thumbnail
/user/
登录页和认证响应
```

## 六、开关如何工作

### 页面加载加速

开启后：

- 启动阶段短时间合并完全相同的安全请求。
- `APP_READY` 后探测服务端插件。
- 登录成功后用同源凭据读取首页 `ETag` 或 `Last-Modified`。
- 把版本签名发送给 Worker；签名变化会清理旧程序缓存。
- 当前版本只在空闲时预热一次。

Worker 不接管页面导航。Basic Auth 的 `401` 挑战、反向代理认证、登录跳转都由浏览器原生处理。

### 聊天与重美化优化

开启后自动执行：

- 打开任何角色聊天时只先加载最后 5 条消息。
- 切换聊天后的首秒内使用 SillyTavern 官方滚动接口保持最后一条可见；用户一旦触碰聊天或加载历史消息便立即取消。
- 点击“显示更多”时使用 SillyTavern 原生流程每页补载 5 条旧消息；插件不再监听到顶滚动，也不再二次修改 `scrollTop`。
- 最近代码优先高亮，旧代码按需高亮并折叠预览。
- 完整 HTML 源码即使没有 `language-html` 类名也会跳过语法高亮，复制按钮和最终美化仍可正常使用。
- 流式生成期间不再随每次 DOM 变化扫描全部代码块；点击停止后会先等待官方生成状态解锁，再合并扫描一次。
- 移动端纵向滚动不再轻易误触左右 Swipe。
- 编辑已有正则、单条开关和批量开关不会立即拆掉整段聊天；插件会比较改动前后的正则，只刷新原始消息中可能匹配的内容。
- 修改状态栏正则时，未包含状态栏标记的剧情选项会保持现有界面；只改名称或只影响提示词时不刷新聊天。
- 调整正则顺序、作用范围，或遇到无法安全判断的宽泛查找式时，会分帧刷新全部已显示消息。

“重新渲染当前聊天”适合修改正则后立即更新当前已显示消息。它先使用局部消息接口；单条失败只显示错误数，只有接口整体缺失时才回退完整聊天重载。

### 界面操作优化

开启后自动执行：

- 预设、正则和世界书完全使用 SillyTavern 原生 sortable 和顺序保存逻辑。
- 电脑端继续按官方行为拖动整条，手机端使用官方拖拽手柄。
- 插件不禁用官方 sortable、不捕获 `pointerdown`、不在拖动期间延迟重建预设列表。
- 生成期间点击预设开关会立即更新图标、当前行样式和官方设置，不执行 Token dry-run，也不重建列表。
- 手机和触控笔会在生成期间于抬起时直接处理开关，并过滤同一开关随后产生的重复 `click`；非生成状态继续由官方点击处理。
- 手机上如果 SillyTavern 弹窗已经关闭或加载内容已被移除，但 Safari 仍将透明 modal 留在 top layer，插件会在安全延迟后解除点击封锁。
- 仍有 SillyTavern 官方活动阻塞任务时不会清理遮罩；快捷回复的透明最小化执行窗被点到时只会展开，不会自动终止脚本。
- 生成真正解锁后，多次开关会合并为一次官方 `renderDebounced()`，重算 Token 并恢复完整列表。

生成期间的切换只影响下一次生成、继续或重新生成，不会改变已经发送给模型的当前请求。

### 启动性能优化

完整安装后，面板会读取 SillyTavern 根目录的 `config.yaml`，并提供两个互不绑定的开关：

- `HTTP Keep-Alive`：可能减少 SillyTavern 后端 HTTP/HTTPS 请求反复建连的开销；某些网络、代理或 API 环境可能出现 `ECONNRESET`、连接中断等异常，遇到后应关闭。
- `角色卡懒加载`：角色超过约 1000 张时通常更有价值；部分未适配的第三方扩展可能失效，高级模糊角色搜索会退化为只按角色名搜索。

开启高风险选项前会再次确认。每次实际修改都先创建 `config.yaml.backup-cloud-lounge-performance-*` 备份；关闭开关会把对应值写回 `false`。所有修改均需重启 SillyTavern 才会影响正在运行的服务器。

## 七、高级信息

展开“高级信息”可查看：

```text
插件版本：2.1.1
页面缓存：正常 / 仅 UI 模式 / 需要 HTTPS / 已停用（服务端需更新）
服务端插件：正常 / 未连接 / 需更新（旧版本号）
已缓存资源：数量
聊天优化：自动 / 关闭
界面操作：生成可切换 / 原生 / 关闭
```

普通面板不再提供帧预算、批量数量、触发距离、加载冷却、第三方扩展缓存或其他危险参数；这些由插件根据设备和聊天复杂度自动选择。

## 八、修复插件

遇到以下情况可以点击“修复插件”：

- 更新后仍出现旧样式。
- Worker 状态异常。
- 缓存资源数长期为 0。
- 页面加载优化未恢复。

修复流程只会停止并重启本插件、注销本插件 Worker、清理本插件缓存、重新注册和预热。不会删除聊天、角色卡、预设、世界书或服务端配置。

页面完全打不开或尚未完成认证时，部署当前版本后在浏览器站点设置中最后清理一次该域名的 Service Worker/站点缓存，然后重新登录。新 UI 发现服务端仍是旧版时会自动注销 Worker，不再把旧 Worker 装回来。当前版本不提供会整页跳转的“本次安全模式”按钮。

## 九、更新与卸载

服务端目录更新：

```bash
git -C plugins/cloud-lounge-accelerator pull
```

UI 扩展可从 SillyTavern 扩展管理器更新。更新完成后刷新页面；服务端文件变化后重启 SillyTavern。

从 2.0.x 早期版本升级到当前版本时：

- 旧设置自动迁移为三个开关。
- 旧版保存的聊天截断原值会恢复。
- 旧 `cloud-lounge-static-*` 缓存在 Worker 激活时清理。
- 不再识别或生成 `?cla-safe=1` 页面跳转。
- UI 与服务端版本不一致时自动停用并注销本插件 Worker；服务端目录必须同步更新并重启 SillyTavern。

卸载时应同时移除 UI 扩展和 `plugins/cloud-lounge-accelerator/` 服务端目录，再重启 SillyTavern。UI 扩展的删除 Hook 会注销本插件 Worker 并清理本插件缓存。

## 十、常见问题

### 显示“仅 UI 模式”

服务端插件没有加载。只需要前端优化时这是正常状态；需要静态缓存时，检查安装路径、`enableServerPlugins: true` 和重启日志。

### 显示“需要 HTTPS”

检查地址是否为 HTTPS、证书是否有效，以及反向代理是否正确传递协议头。

### 域名 Basic Auth 弹不出来

先确认 UI 扩展和服务端插件都已更新到当前版本，并在更新服务端后重启 SillyTavern。然后在浏览器站点设置中最后清除一次该域名的旧 Service Worker。新版不会接管页面跳转；如果以后两处版本再次不一致，UI 会自动注销旧 Worker 并停止重新注册。

### 显示“服务端插件需更新”

酒馆内的自动更新只更新了 UI 扩展，服务端插件还是旧版。运行一键安装/更新脚本同步两个目录，重启 SillyTavern，再刷新页面。版本一致后页面缓存会自动恢复。

### 第二次访问仍然慢

- 高级信息中缓存数量为 0：点击“修复插件”。
- 首字节慢：检查服务器区域、线路、TLS、1Panel 反代和上游负载。
- DOM 渲染慢：暂停不需要的大型美化扩展或检查生成超大 HTML 的正则。
- 角色很多：启用 SillyTavern 官方 `performance.lazyLoadCharacters`。

### 拖拽显示“原生”

当前版本仍不修改拖拽列表；“生成可切换”只代表生成期间的预设开关可以立即保存。如果仍有拖拽异常，请更新 SillyTavern，并检查是否安装了其他会接管相同列表的扩展。

### 正则修改后旧消息没有变化

编辑已有正则后先等待自动精准刷新；未命中的消息会保持原样。新增、删除、移动、调整顺序或作用范围等高风险操作可能刷新全部已显示消息。需要强制重做所有当前消息时，再点击“重新渲染当前聊天”。

## 十一、安全说明

- 服务端插件不受 SillyTavern 扩展沙箱保护；本项目服务端只提供健康检查、Worker 脚本和两项明确授权的性能配置接口，只有用户操作面板开关时才备份并修改对应配置。
- 本插件不缓存 API、账号、聊天、角色、背景、缩略图、用户文件或第三方扩展资源。
- 不要在没有 SillyTavern 账号、Cloudflare Access、Tailscale 或其他可信访问控制时把实例直接暴露到公网。
- “修复插件”和卸载只处理以 `cloud-lounge-static-` 开头的本插件缓存，不处理其他站点数据。
