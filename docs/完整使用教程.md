# 云酒馆加速器 2.0.4 完整使用教程

## 一、先选择安装模式

云酒馆加速器由两部分组成：

- UI 扩展：页面启动、聊天、正则、预设、拖拽和抽屉优化。
- 服务端插件：提供根作用域 Service Worker，用于程序静态资源缓存。

| 你的环境 | 推荐方式 |
| --- | --- |
| 自己管理 SillyTavern 服务器、容器或本机目录 | 安装 UI + 服务端插件 |
| 只能在酒馆内安装扩展 | 只安装 UI |
| 没有 HTTPS，也不是 localhost | 先用 UI；静态缓存会显示“需要 HTTPS” |

只安装 UI 也能使用聊天和界面优化。服务端插件缺失不会阻止扩展启动。

## 二、一键安装完整增强

### Linux、macOS、1Panel Xterminal

先进入 SillyTavern 根目录：

```bash
cd /root/SillyTavern

curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash
```

如果你的 SillyTavern 不在 `/root/SillyTavern`，请把第一行改成实际路径。也可以直接把路径传给安装脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.sh | bash -s -- /path/to/SillyTavern
```

### Windows PowerShell

```powershell
& ([scriptblock]::Create((irm 'https://raw.githubusercontent.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator/main/scripts/install.ps1'))) -SillyTavernRoot 'C:\SillyTavern'
```

脚本完成后手动重启 SillyTavern。安装器不会猜测并重启你的 1Panel 容器或服务名称。

一键安装会：

1. 把仓库安装到 `plugins/cloud-lounge-accelerator/`。
2. 把 UI 文件安装到默认用户的扩展目录。
3. 备份需要调整的配置。
4. 提示你确认 `enableServerPlugins: true`。

## 三、手动安装

### 只安装 UI

在 SillyTavern 中打开“扩展 → 安装扩展”，输入：

```text
https://github.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator
```

安装后刷新页面。打开“扩展设置 → 云酒馆加速器”即可看到三个开关。

### 安装服务端插件

进入 SillyTavern 根目录：

```bash
git clone https://github.com/soso454u/SillyTavern-Cloud-Lounge-Accelerator.git plugins/cloud-lounge-accelerator
```

已有目录时更新：

```bash
git -C plugins/cloud-lounge-accelerator pull
```

确认目录结构：

```text
SillyTavern/
├─ plugins/
│  └─ cloud-lounge-accelerator/
│     ├─ package.json
│     ├─ manifest.json
│     ├─ index.js
│     └─ server/
│        ├─ index.js
│        └─ worker-template.js
└─ config.yaml
```

确认 `config.yaml`：

```yaml
enableServerPlugins: true
```

角色较多时可再确认 SillyTavern 官方性能设置：

```yaml
performance:
  lazyLoadCharacters: true
  memoryCacheCapacity: '100mb'
  useDiskCache: true

cacheBuster:
  enabled: false
```

不要创建重复的 `performance:` 或 `cacheBuster:` 段；只修改现有配置项。

重启后，日志应包含：

```text
Initializing plugin from .../cloud-lounge-accelerator/server/index.js
```

## 四、配置 HTTPS

Service Worker 只能在 HTTPS 或 localhost 使用。云服务器上应从 `https://你的域名` 访问，而不是裸 `http://IP:端口`。

没有自有域名时，可以使用 `sslip.io` 这类把 IP 编入主机名的公共解析服务。例如服务器 IP 为 `23.94.194.240`：

```text
23-94-194-240.sslip.io
```

在 1Panel 中：

1. 新建反向代理网站，主域名填上述主机名。
2. 上游填 `http://127.0.0.1:8000`，端口按实际修改。
3. 用 HTTP 验证申请 Let's Encrypt 证书。
4. 开启 HTTPS，并传递 `X-Forwarded-Proto $scheme`。
5. 此后从 HTTPS 地址进入酒馆。

如果证书报错、页面不是安全上下文或浏览器策略禁用 Service Worker，页面缓存会保持关闭，其他优化仍可使用。

## 五、1Panel 反向代理静态优化

仓库中的 [`1panel/nginx-static.conf.example`](../1panel/nginx-static.conf.example) 只匹配程序静态目录。

操作前：

1. 备份当前站点配置。
2. 把片段放进已有 `server { ... }` 内。
3. 把 `proxy_pass http://127.0.0.1:8000;` 改为当前 SillyTavern 上游。
4. 如已有相同正则 `location`，合并配置，不要叠加冲突规则。
5. 通过 1Panel 配置检查后再重载 OpenResty/Nginx。

不要缓存以下内容：

```text
页面导航
/api/
/characters/
/backgrounds/
/thumbnail
/user/
登录页和认证响应
```

## 六、三个开关如何工作

### 页面加载加速

开启后：

- 启动阶段短时间合并完全相同的安全请求。
- `APP_READY` 后探测服务端插件。
- 登录成功后用同源凭据读取首页 `ETag` 或 `Last-Modified`。
- 把版本签名发送给 Worker；签名变化会清理旧程序缓存。
- 当前版本只在空闲时预热一次。

Worker 不接管页面导航。Basic Auth 的 `401` 挑战、反向代理认证、登录跳转都由浏览器原生处理。

### 聊天与重美化优化

开启后自动执行：

- 打开任何角色聊天时只先加载最后 5 条消息。
- 点击“显示更多”时使用 SillyTavern 原生流程每页补载 5 条旧消息；插件不再监听到顶滚动，也不再二次修改 `scrollTop`。
- 最近代码优先高亮，旧代码按需高亮并折叠预览。
- 完整 HTML 源码即使没有 `language-html` 类名也会跳过语法高亮，复制按钮和最终美化仍可正常使用。
- 移动端纵向滚动不再轻易误触左右 Swipe。
- 编辑已有正则、单条开关和批量开关不会立即拆掉整段聊天；插件会比较改动前后的正则，只刷新原始消息中可能匹配的内容。
- 修改状态栏正则时，未包含状态栏标记的剧情选项会保持现有界面；只改名称或只影响提示词时不刷新聊天。
- 调整正则顺序、作用范围，或遇到无法安全判断的宽泛查找式时，会分帧刷新全部已显示消息。

“重新渲染当前聊天”适合修改正则后立即更新当前已显示消息。它先使用局部消息接口；单条失败只显示错误数，只有接口整体缺失时才回退完整聊天重载。

### 界面操作优化

开启后自动执行：

- 预设、正则和世界书完全使用 SillyTavern 原生 sortable 和顺序保存逻辑。
- 电脑端继续按官方行为拖动整条，手机端使用官方拖拽手柄。
- 插件不禁用官方 sortable、不捕获 `pointerdown`、不在拖动期间延迟重建预设列表。

高级信息中该项显示“原生”表示插件已将交互所有权交还 SillyTavern，不是故障。

## 七、高级信息

展开“高级信息”可查看：

```text
插件版本：2.0.4
页面缓存：正常 / 仅 UI 模式 / 需要 HTTPS
服务端插件：正常 / 未连接
已缓存资源：数量
聊天优化：自动 / 关闭
界面操作：原生 / 关闭
```

普通面板不再提供帧预算、批量数量、触发距离、加载冷却、第三方扩展缓存或其他危险参数；这些由插件根据设备和聊天复杂度自动选择。

## 八、修复插件

遇到以下情况可以点击“修复插件”：

- 更新后仍出现旧样式。
- Worker 状态异常。
- 缓存资源数长期为 0。
- 页面加载优化未恢复。

修复流程只会停止并重启本插件、注销本插件 Worker、清理本插件缓存、重新注册和预热。不会删除聊天、角色卡、预设、世界书或服务端配置。

页面完全打不开或尚未完成认证时，直接使用浏览器站点设置清理该域名的 Service Worker/站点缓存，然后重新登录。2.0.4 不提供会整页跳转的“本次安全模式”按钮。

## 九、更新与卸载

服务端目录更新：

```bash
git -C plugins/cloud-lounge-accelerator pull
```

UI 扩展可从 SillyTavern 扩展管理器更新。更新完成后刷新页面；服务端文件变化后重启 SillyTavern。

从旧版升级到 2.0.4 时：

- 旧设置自动迁移为三个开关。
- 旧版保存的聊天截断原值会恢复。
- 旧 `cloud-lounge-static-*` 缓存在 Worker 激活时清理。
- 不再识别或生成 `?cla-safe=1` 页面跳转。

卸载时应同时移除 UI 扩展和 `plugins/cloud-lounge-accelerator/` 服务端目录，再重启 SillyTavern。UI 扩展的删除 Hook 会注销本插件 Worker 并清理本插件缓存。

## 十、常见问题

### 显示“仅 UI 模式”

服务端插件没有加载。只需要前端优化时这是正常状态；需要静态缓存时，检查安装路径、`enableServerPlugins: true` 和重启日志。

### 显示“需要 HTTPS”

检查地址是否为 HTTPS、证书是否有效，以及反向代理是否正确传递协议头。

### 域名 Basic Auth 弹不出来

先确认已更新到 2.0.4，然后在浏览器站点设置中清除该域名旧的 Service Worker。新版不会接管页面跳转，也不会缓存认证提示。

### 第二次访问仍然慢

- 高级信息中缓存数量为 0：点击“修复插件”。
- 首字节慢：检查服务器区域、线路、TLS、1Panel 反代和上游负载。
- DOM 渲染慢：暂停不需要的大型美化扩展或检查生成超大 HTML 的正则。
- 角色很多：启用 SillyTavern 官方 `performance.lazyLoadCharacters`。

### 拖拽显示“原生”

2.0.4 开始这是正常状态。插件不再修改拖拽列表；如果仍有拖拽异常，请更新 SillyTavern，并检查是否安装了其他会接管相同列表的扩展。

### 正则修改后旧消息没有变化

编辑已有正则后先等待自动精准刷新；未命中的消息会保持原样。新增、删除、移动、调整顺序或作用范围等高风险操作可能刷新全部已显示消息。需要强制重做所有当前消息时，再点击“重新渲染当前聊天”。

## 十一、安全说明

- 服务端插件不受 SillyTavern 扩展沙箱保护，但本项目服务端只提供健康检查和 Worker 脚本。
- 本插件不缓存 API、账号、聊天、角色、背景、缩略图、用户文件或第三方扩展资源。
- 不要在没有 SillyTavern 账号、Cloudflare Access、Tailscale 或其他可信访问控制时把实例直接暴露到公网。
- “修复插件”和卸载只处理以 `cloud-lounge-static-` 开头的本插件缓存，不处理其他站点数据。
