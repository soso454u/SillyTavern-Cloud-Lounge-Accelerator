# 预设分类与折叠修复 · 2.1.80

## 故障与实现

旧 `folderLayout()` 按原始顺序切片，同一 folderId 会生成多个标题；未分类直接散在根列表。`setFold()` 通过 `commit()` 进入 `render()`，先清理标题和样式再重建，叠加浏览器滚动锚定和高度收缩，点击位置不再稳定。多选的旧 CSS 还会关闭原生编辑/开关的 pointer events。

现在 `preset-folder-model.js` 产生唯一文件夹节点及完整 children，未分类也是独立文件夹。`preset-entry-groups.js` 按 folderId 复用 DOM，把真实原生条目移入子列表，保留原监听器；关闭分类或切换原始顺序时按当前 prompt_order 恢复直接子节点。分类期间阻止 sortable，原始视图恢复其原配置。原生重渲染后放弃断开的旧节点，避免复用出重复行。token 预览同步改为按 identifier 搜索后代。

折叠不调用原生 render，不重建文件夹，只局部切换 `collapsed`。`preset-scroll-anchor.js` 记录标题的屏幕位置和祖先滚动容器，局部更新后按 rect 差值校正，并在下一帧再校正一次；临时关闭原生 overflow-anchor，随后恢复。多个操作不会让旧回调覆盖新锚点。页面缩短到物理上无法保持原位置时保留标题可见，不插入永久补偿空白。

## 识别与设置

规则引擎在 `preset-section-boundaries.js`，设置界面在 `preset-recognition-settings.js`。普通文本模板支持一个 `{name}`，高级正则在保存、导入前校验；默认只匹配 name，正文范围必须由用户明确选择。按规则族、完整名称和堆栈配对，交叉、歧义及未闭合区间保持原生条目。单标题需明确启用，支持层级，在明确成对边界结束；不会随意关闭成对区间。单标题的稳定 key 不依赖区间最后一条内容。

优先级为手动归类、手动区间、自定义规则、内置规则。同类规则可调整顺序，冲突在折叠诊断中提示。默认推荐箭头方括号与中文书名号成对模板；单标题等号默认关闭。显示设置默认收起，内含文件夹操作、规则管理和分类导入/导出。隐藏标记只影响已成功识别标记的视觉，手动归属优先。

沿用原设置 key 和 schema 4，补充 recognition，不破坏旧文件夹、手动关系及折叠状态。旧 sectionKey 按真实开始 identifier 迁移；停用规则仅移除派生归属，保留元数据。自定义规则随分类导入导出，无效正则拒绝导入。

用法：分类设置 → 添加自定义规则 → 选择成对头尾，填写 `====↓[{name}]↓====` 与 `====↑[{name}]↑====` → 保存。可以随时关闭、编辑规则，或选择关闭/成对/单标题/混合模式。无需逐项审核。
